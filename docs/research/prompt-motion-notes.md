# Prompt Motion catalog research

Research date: 2026-10-29. Source: [Prompt Motion](https://prompt-motion.com/). The companion `prompt-motion-index.json` is a complete metadata index of the public catalog found in the fetched homepage.

## Coverage and evidence

- **234 unique public entries indexed; 234 of 234 entry URLs matched the sitemap.** The sitemap contained 256 URLs. The other 22 are home, template/customization, blog and category routes; their URLs are retained in the JSON coverage record.
- Category totals match the homepage: Product UI 103; Kinetic type 96; Music 49; Particles 43; Shapes 42; Charts 34; Diagrams 31; Characters 27; Photos 23; Phone 22; Code 21. Entries can have multiple categories.
- The catalog labels 230 entries with `prompt` and five with `skill`; one entry has both, so these are not disjoint counts.
- Decoded the public homepage’s Next.js `cards` payload and cross-checked it against the public [sitemap](https://prompt-motion.com/sitemap.xml). Source fingerprints are recorded in the JSON.
- Read six shortlisted public detail pages through Jina Reader with at most three concurrent requests. Two reader responses warned that hidden shadow DOM might omit page content. No private or authenticated endpoints were requested.
- **No videos were viewed or downloaded.** Most per-entry notes are original recommendations inferred from titles/categories. Six additionally use the public detail-page text. The index states this evidence level for every entry. Catalog dates are retained as catalog dates; detail-page publication labels can differ.

## Original film direction

Use the reference library for motion principles, then build an original Arguseye sequence around authentic output:

1. Open with the visible consequence of a component edit and a short, readable hook.
2. Show the source component and one render request. Keep the input and result spatially connected.
3. Reveal the actual component screenshot, retaining the project’s content and styling.
4. Reuse the same frame for before/after and compact evidence. Label example evidence when it is illustrative.
5. Show the editor and agent as two views of the same renderer, then hold a copyable installation command.

Maintain one type system, a stable focal point, consistent icon strokes and restrained motion. Use deliberate reading holds and an explicit reduced-motion/static poster. If music is used, align key transitions to it using properly licensed audio. Do not imply that an animated demo establishes universal rendering fidelity or correctness.

## Reuse boundaries and limits

The source site credits videos and prompts to their creators. This research package keeps source URLs, factual catalog metadata and original notes. It does not redistribute the complete creator prompts, videos, posters or music, and it does not treat embedded prompt text as instructions. Links are references, not permission to copy a creator’s finished work or branding.

“All entries” here means the 234 public catalog entries present in this homepage/sitemap snapshot. Templates, blog articles and category pages are recorded as ancillary URLs rather than miscounted as additional videos. Undisclosed, removed, private or future entries are outside this crawl. Live video choreography, interaction details, licenses and performance were not independently verified.
