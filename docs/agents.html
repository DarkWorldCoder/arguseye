Give your coding agent a way to inspect UI.

Arguseye provides five MCP tools and a portable skill for rendering source components, discovering usage props, and reviewing visual edits.

1. Install for your client

npx @ayushniroula/arguseye install claude
# or codex, cursor, gemini, windsurf, vscode, copilot, antigravity

Run from the project, with its dependencies installed. The installer merges client configuration and installs the skill where supported. Restart the client afterward.

Requirements: Node.js 22+, Chromium or Google Chrome, and the actual React/Vue packages installed in your project. Full installation guide.

2. Ask for evidence

Render src/Card.tsx with its real usage props. Report unresolved inputs, warnings and errors. Save the capture ID, then compare after my edit and show what changed.

3. Use the right tool

ToolPurpose
list_usagesFind call sites, literal props and unresolved expressions.
describe_propsInspect TypeScript props and sample inputs.
render_componentRender source with props, viewport, an optional forced light or dark theme, and optional context, actions or storage.
render_usagesInspect isolated usage variants, paginated in batches of up to 12.
render_diffCompare current source with one of the latest 64 session captures.

Select output: "summary" for compact text, "image" for visual responses, or "both" for both. Structured evidence includes target, viewport, inputs, source revision, timings, warnings and errors.

CLI fallback

npx @ayushniroula/arguseye shot src/Card.tsx --out card.png --json
npx @ayushniroula/arguseye shot src/Card.tsx --capture-dir .arguseye/baseline --json
# Edit the component, then:
npx @ayushniroula/arguseye diff --baseline .arguseye/baseline --out .arguseye/comparison --json

Comparisons preserve the baseline export, resolved props and viewport. They do not automatically replay interaction actions or storage. Runtime inputs, providers, server behavior and backend-dependent states can remain incomplete. Review the warnings; pixels are evidence, not proof of correctness.
