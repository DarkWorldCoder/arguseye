Know what the preview can tell you.

Render with your own packages, global styles and statically reconstructable layouts. If props need runtime data or a provider cannot be reconstructed, the result reports it.

Use application-level browser tests for authentication, backend state and complete user journeys. Component evidence helps you inspect the UI along the way.

Get answers before you install.

Do I need a running app or authored stories?

No. Arguseye renders component source directly, using packages installed in your project. You still need the project’s dependencies and Node.js 22 or later. Chromium is required for headless rendering; setup details are in the installation guide.

Which components can I preview?

React components, browser-renderable Next.js components, and Vue 3 single-file components. Project CSS, Tailwind, Sass, CSS modules and assets are supported. Next.js server execution, Nuxt application context and arbitrary runtime providers are outside the current release.

What does my agent receive?

A cropped PNG, accessibility snapshot, resolved and unresolved inputs, source fingerprint, timings, warnings and errors. Choose image, summary or both. Successful renders receive a capture ID for later comparison. The CLI is available when your agent has no MCP support.

Does a clean render mean the change is correct?

No. Arguseye shows pixels and structured evidence, including what changed and any incomplete context. Review the result against the intended behavior and use integration tests for complete application flows.

Can I use it without an AI agent?

Yes. Install the VS Code extension, open a component and run Preview Component. Choose an export, usage or viewport; capture a baseline and compare unsaved edits. The same engine powers the CLI and MCP tools.
