Describe it in a sentence.

Arguseye renders React, browser-renderable Next.js and Vue components from project source so coding agents and developers can inspect UI edits without starting the app or writing stories.

A little more detail

Arguseye is an MIT-licensed local preview engine for coding agents and VS Code developers. It renders supported React, browser-renderable Next.js and Vue 3 components using a project’s own source, packages and styles. Agents can discover literal props from real usages, inspect screenshots and accessibility text, and compare edits against saved baselines. The VS Code extension previews unsaved edits through the same engine. Unresolved inputs, errors and missing context stay visible. Isolated previews support review alongside application tests.

The workflow

A small loop for a small edit.

Start with the component that already exists in the project.

  1. 01

    Render the component

    Use literal props discovered at a real call site, or supply explicit inputs. Read unresolved values and context warnings.

  2. 02

    Edit its source

    Inspect a live preview beside your code, or ask your coding agent to render again after its edit.

  3. 03

    Review the consequences

    Compare pixels, dimensions, accessibility text and errors. A difference shows what to inspect; it does not decide correctness.

Compatibility

Keep the scope in the story.

Project dependencies must be installed. Headless agent and CLI use requires Node.js 22+ and Chromium or Google Chrome. Vue projects use their own matching Vue runtime and compiler.

Runtime-only props, arbitrary providers, authentication and backend states, Next.js server execution and Nuxt context can remain incomplete. The returned warnings identify gaps in the evidence.

Performance varies by project and workload. The recorded benchmarks include their method and machine.

Try it in a project
