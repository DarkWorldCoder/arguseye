# Storylines

1. **How an agent sees (built).** One real bug, end to end: an agent edits a pricing button, it breaks on a phone,
   Arguseye shows the project being read (component, call sites, props, layouts, theme, CSS, fonts, images,
   packages, Chromium) and the agent fixes it from the real result. Picked because it explains how the system works
   with real, live components, which is what the owner asked for after the first cut.
2. **The visible edit (previous cut, launch-video/).** The same loop told on a production app's screens. Replaced:
   the owner asked for no app screenshots.
3. **Through the eye.** An endless zoom through the mark into each stage of the render. Bolder, weaker at teaching
   one real task.
